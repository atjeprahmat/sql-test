2. Tutorial Penyegaran Sintaks SQL

A. Operasi Manipulasi Data (DML)

Gunakan INSERT untuk menambah data, dan UPDATE dikombinasikan dengan klausa WHERE agar tidak merubah seluruh isi tabel.

-- Contoh Tambah Data
INSERT INTO nama_tabel (kolom1, kolom2) VALUES ('Nilai1', 'Nilai2');

-- Contoh Mengubah Data Spesifik
UPDATE salaries SET salary = salary * 1.1 WHERE emp_no = 10001;

B. Fungsi Agregasi & Grouping

Saat menggunakan fungsi agregat seperti COUNT, SUM, atau AVG bersama dengan kolom non-agregat, Anda wajib mendeklarasikan klausa GROUP BY.

SELECT kode_kategori, COUNT(kode_produk) AS total_item
FROM ms_produk
GROUP BY kode_kategori;

C. Menggabungkan Banyak Tabel (Multi-Table JOIN)

Pastikan kondisi kunci utama (Primary Key) dan kunci tamu (Foreign Key) terpasang presisi pada klausa ON.

SELECT e.first_name, d.dept_name
FROM employees e
INNER JOIN dept_emp de ON e.emp_no = de.emp_no
INNER JOIN departments d ON de.dept_no = d.dept_no;
